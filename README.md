# HippoType

A typing speed game that measures how fast and accurately you can type under 30 seconds.

![](final.png)

## Anyone can Try it here:

**(https://davidx-004.github.io/HippoTypingGame/)**

## Features

- 30 second timed typing rounds
- Live feedback: correct letters turn green, mistakes turn red as you type
- Automatic WPM (words per minute) score at the end of each round so you can get your speed result
- New game button to restart the game 

## If you want to Run it locally just do the following steps:

1. Clone or download this repo
2. Open `index.html` in any browser
3. Click the text area to focus, and start typing

## How it works

Every word on screen is split into single letters. When you press a key, the game checks that letter against the one you were supposed to type and colors it green if its right or red if its wrong. A word only adds to your score if you typed all of its letters correctly.

The clock only starts when you type your very first letter just to give you the accurate time measurement.
